# Java Learning Repository Structure

This repository has been reorganized into a more structured format to enhance learning and navigation. Below is the new layout:

```
learn_Java_language/
├── docs/             # Documentation files related to Java concepts
│   └── [...]
├── src/              # Source files
│   ├── main/java/    # Java source files organized by topic/package
│   │   └── [...]
│   └── test/java/    # Java test files
│       └── [...]
├── examples/         # Runnable examples
│   └── [...]
```

## Changes Made
- Moved Java source files into appropriate packages under `src/main/java/`
- Grouped test files into `src/test/java/`
- Documentation files have been moved into the `docs/` folder.
- Runnable sample programs have been placed in the `examples/` folder, where applicable.

Make sure to navigate through the newly created structure to find relevant files easily!
